# 刻迹 iOS 工作台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将评审原型落实为原生、可同步、可访问的个人与 AI 工作台。

**Architecture:** 复用 AppStore / StateStore / SyncEngine，增加 Plan 独立领域和 API。UI 订阅服务器执行状态；本地可编辑草稿，但不能从倒计时或动画产生“执行成功”。

**Tech Stack:** SwiftUI、iOS 17+、Swift 5、XCTest/XCUITest；路径相对 TimeTrace 仓库。

**Spec:** [产品设计](../specs/2026-09-14-keji-ai-timeline-product-design.md)、[总计划/API](2026-09-14-keji-ai-workspace.md)、[设计原型](http://127.0.0.1:5194/review)。

## Global Constraints

- 最新导航确认优先：底部 today/projects/timeline/ai/mine。reports改为今日右上角及项目详情的二级入口，返回原来源页；项目报告列表、统计、建议和导出保持项目范围。个人中心根页无返回按钮，子页返回「我的」，保留底部导航。下文旧reports主Tab/profile头像描述以本条为准。

- 业务层级固定为项目 → 任务 → Plan；Goal 是版本范围，不新增第四级目录。
- 自动续杯指订阅额度自然恢复后自动续跑暂停的 Plan，不额外付费。
- 未知额度不等于满额；所有状态同时用文字与图形表达。
- 人工时间与并行 AI 时间分别显示，不简单相加。
- 生产力数据覆盖不足时只展示分项与原因。
- 保留最终 Logo；iOS 17 最低版本不变；总计划其他约束全部适用。

```swift
import CryptoKit

func defaultPlanID(taskID: String) -> String {
    let bytes = Data("timetrace:default-plan:v1:\(taskID)".utf8)

}
```

```swift
enum TimelineTrack: String { case human, ai, waiting }
struct TrackInterval { let start: Date; let end: Date; let track: TimelineTrack }
func activeSeconds(_ intervals: [TrackInterval], track: TimelineTrack) -> TimeInterval {
    intervals.filter { $0.track == track }.reduce(0) { $0 + max(0, $1.end.timeIntervalSince($1.start)) }
}
```

```swift
func quotaLabel(remaining: Double?, fresh: Bool) -> String {
    guard fresh else { return "待核验" }
    guard let remaining, remaining.isFinite, (0...100).contains(remaining) else { return "未知" }
    return "\(Int(remaining.rounded()))%"
}
```
