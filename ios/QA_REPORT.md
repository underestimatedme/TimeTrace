## 自动化入口

从仓库根目录运行：

```sh
bash ios/scripts/run-qa.sh
```

可使用 `SIMULATOR_NAME` 指定已安装的模拟器。脚本生成 Xcode 工程，依次运行单元、HTTP 协议和 UI 测试，并把 `.xcresult` 与截图导出到 `ios/qa-artifacts/<时间戳>/`。CI 也会上传完整测试结果。

本次最终证据位于 `ios/qa-artifacts/final/`，包括 20 张功能截图和 `manifest.json`。完整 Xcode 结果位于 XcodeBuildMCP 的 result bundle 中。

## 范围限制

当前项目中的 AI 执行与 AI 工具连接仍是产品规格定义的模拟逻辑，尚未接入 Claude、Codex 或其他真实模型。自动化确认的是模拟状态机、计时、审核和页面行为。手机号/邮箱验证码、生产账号写入/删除及多设备同步没有对生产环境执行破坏性测试；生产 API 的只读健康检查返回 HTTP 200，服务版本为 1。
